# ESTILO POR ACTIVITY TYPE (borrador para revisar)
# Lo que el Activity Type le agrega a la frase del evento: una APERTURA antes y/o un CIERRE después.
# Se elige según el TONO del evento (bueno, malo, neutro; cada evento dice el suyo).
# Formato: tono.antes | texto     o     tono.despues | texto
# Etapas: "nino" = Child; "maduro" = Adult, Perfect y Ultimate (aquí no hay "maduro 2").
# Las aperturas terminan como deben empezar la frase ("¡Sí!", "Uf...").
#
# Cuánto se usa (probabilidad de agregar cada parte):
#                 Child, Adult, Perfect     Ultimate (la mitad, y SOLO apertura)
#   estoico          10 %                      5 %   (y prefiere la frase MÁS CORTA del evento)
#   activo           40 %                     20 %
#   normal           25 %                     12 %
#   interior         35 %                     17 %
#   perezoso         30 %                     15 %
#
# Ultimate: nunca lleva cierre. Sus frases ya terminan fuertes a propósito y el cierre les sumaba
# una segunda idea que las contradecía ("Esto no acaba aquí. Volveré." + "Mañana lo intento... o
# pasado."). Por eso aquí no hay sección "maduro 2": usa las aperturas de "maduro".
#
# Para que no se repita nada (TODAS las etapas y atributos):
#   1. Si la frase ya empieza con una exclamación o sonido, no lleva apertura ("¡Ja!" + "Je. Ni
#      siquiera tuve que esforzarme." no sale). Cuentan: Ja, Je, Jeje, Jiji, Tsk, Hmph, Hmm, Mm,
#      Bah, Uf, Uy, Ay, Uh, Oh, Grr, Snif, Rayos, Diablos, Demonios, Maldición, Yay, Ups, Ey, Oye,
#      Eh, Mira, Vaya, Ta-da, Ding... (las mismas que usan las aperturas de este archivo).
#   2. Si la apertura o el cierre repite una palabra de la frase, no se usa: se elige otro o
#      ninguno ("Snif... no entiendo." + "...snif." no sale; "Algo aprenderé de esto." + "Aprendo."
#      tampoco). Se comparan palabras de 3 letras o más, sin tildes ni mayúsculas, por su raíz
#      (las 5 primeras letras: aprenderé = aprendo), sin contar que, con, por, los, las, una, uno,
#      del, sin, muy.
#   3. La misma apertura o el mismo cierre no vuelve a salir en sus 3 reacciones siguientes
#      (de cualquier evento), para que no diga "¡Sí!" en todo.

=== estoico ===
# Pocas palabras, sereno. Casi nunca agrega nada: su forma de hablar es la frase corta.
--- nino ---
bueno.antes | Mm.
bueno.despues | Bien.
malo.antes | ...
malo.despues | Sigo.
neutro.antes | Mm.
--- maduro ---

malo.despues | Aprendo.
neutro.antes | Hmm.
neutro.despues | Eso es todo.
